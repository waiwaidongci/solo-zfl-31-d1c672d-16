# 手工织锦纹样排版台 · 上机织造

在原有纹样排版台基础上扩展**上机织造仿真与穿综编排**:色线映射经线、登记综框与提花线号、
穿筘密度、按梭序安排纬线换色与边组织,展开每投一纬的开口序列并联查,支持拖动重排与回放。

## 使用

- 直接双击打开 `index.html`(无需构建,file:// 可用);
- 或 `npm start` 后访问 http://127.0.0.1:8734 (ES 模块零依赖,两种打开方式等价)。

页面分两个标签:

- **纹样绘制**(原有功能):网格绘制、色线统计、撤销/重做、本地保存、导出 JSON。
  旧版保存数据(localStorage `zfl31Pattern`)与旧版导出格式完全兼容。
- **上机织造**(新增):
  - *经线映射*:色线 → 每根经纱的颜色(默认取列主色,可点改);
  - *综框登记*:增删综框、编辑提花线号与综丝容量、拖动/按钮换序;
  - *穿筘与边组织*:每筘齿穿入数、筘密、边经数(固定 2 片边综、平纹边)、浮长上限、纹样重复;
  - *梭序*:每投一纬的行号与色线,拖动 ≡ 或 ▲▼ 调序,可增删;
  - *穿综图*:拖动经纱到别的综框、拖动左侧线号给综框换序;手机上点经纱再点目标综框;
  - *开口序列*:每投一纬各综框起落,点击任意投跳转;
  - *织物模拟 + 回放*:按当前穿综与梭序织出的布面,织口线随回放推进;
  - *联查报告*:任何调整后立即重算(见下)。

## 织造模型与联查规则

- **开口规则**:第 p 投(色 c)在列 x 处,纹样格 === c 则经沉纬浮(纬线露面),否则经浮纬沉。
- **穿综编排**:开口需求完全相同的经纱可同综;同一筘齿内的经纱不得同综框(相邻经纱会绞缠);
  每框不超过登记的综丝容量。自动编排为**填补式**:保留手工已穿的经纱,只为未穿的补位。
- **联查**(拖动综框、经线或梭序后立即重算):
  1. 综框容量超限;2. 同筘同综(相邻经纱冲突);3. 同框开口不一致 → **首个受阻纬线**;
  4. 经/纬浮长超上限(警示);5. 换梭顺序——同一色梭相邻两投须隔奇数投,
  否则梭子回不到出发侧;6. 提花线号重复。
- **无解**:开口组合数超过登记的综框数时,编排停在最后安全筘齿前,
  指出受阻经纱、所在筘齿与原因(`FRAMES_EXHAUSTED`),穿综图上以红线与灰区标出。
- **默认梭序**:每行按色线首次出现取色,行内色序回溯搜索,使同色梭间隔全为奇数
  (默认方案即满足换梭顺序);找不到时退化为蛇形贪心,余下冲突由联查如实报告。
- **导出/导入**:完整方案(纹样 + 上机配置)JSON;兼容导入旧版纹样导出(仅 cols/rows/cells)。

## 计算与页面各自独立

```
src/engine/loom-engine.js   纯计算引擎(UMD,零 DOM):开口位图、自动穿综、联查、开口序列、序列化
src/ui/                     页面:pattern-tab(纹样)/ loom-tab(织造)/ canvas-grid(画布与指针)
tests/engine.test.js        引擎单测(node:test,19 例)
tests/e2e/loom.spec.js      真实浏览器录制(Playwright,桌面 + 手机)
```

引擎同时支持浏览器 `<script src>` 与 Node `require()`,不引用任何 DOM。

## 测试与录制

```bash
npm install                 # 安装 Playwright
npx playwright install chromium
npm test                    # 引擎自动化测试(合法/容量/相邻/受阻/换梭/浮长/无解/导入导出/性能)
npm run test:e2e            # 真实浏览器:桌面 + 手机两个 project
npm run record              # 同上:合法编排、冲突、重排、换梭、无解、导出导入、旧纹样回归
```

录制产物(视频 + 截图)写入 `recordings/`。本容器无 root,chromium 系统库已解压至
`.syslibs/` 并由 `playwright.config.js` 经 `LD_LIBRARY_PATH` 注入;有 root 的环境
直接 `npx playwright install --with-deps chromium` 即可。
